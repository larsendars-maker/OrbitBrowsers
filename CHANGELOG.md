# Orbit Browser Changelog

## 2.3 — Unified Release

- Единая версия 2.3 для Windows, Android, backend и сайта.
- Windows CI публикует только `OrbitBrowser.exe`.
- Android CI собирает только `OrbitBrowser.apk`; AAB не публикуется.
- Исправлен fallback Android WebView: ошибки загрузки больше не отправляют пользователя в мини-игры.
- Мобильный GUI адаптирован по размеру экрана, увеличены верхняя и нижняя панели.
- Авторизация/регистрация выровнены между Windows и Android.
- Темы и титулы профиля разделены и сохраняются в правильные поля.
- Добавлены варианты компоновки интерфейса вместо простого переключения цветов.
- Старт и загрузка погоды не блокируют первое отображение интерфейса.
- Сайт полностью переработан: новый hero, загрузки платформ, релизы, FAQ и аккуратная мобильная верстка.

## 2.2 — GUI / Android

- Адаптивный мобильный GUI.
- Панели и зоны нажатия увеличены для телефонов.
- Исправлены Android build workflow и поиск готового APK.

## 2.1 — Performance / UI

- Варианты интерфейса: базовый, Google-like, минимализм, компактный и стекло.
- Ускорен старт и вынесена погода в фон.

## 2.0 — Orbit Core

- Общая архитектура Windows, Android, backend и сайта.
- Быстрый запуск UI, SQLite/WAL, восстановление сессии и Command Center.

## 1.12 — Performance / Core

- SQLite становится основным локальным хранилищем.
- `Ctrl+K` — Orbit Command Center.
- Расширенное восстановление закрытых вкладок.

## 1.11 — Final Polish

- Производительность и быстрый запуск.
- Single-window UX.
