# Orbit Browser — Changelog

## 1.0 — First public release
- Базовый браузер для Windows и Android.
- Orbit Search по умолчанию.
- Профили и авторизация без автоматического создания пользователя.
- История, закладки и загрузки.
- Orbit Studio и темы.
- Синхронизация поддерживаемых данных.
- Офлайн-режим с Snake и Block Blast.
- Прямое скачивание Windows EXE и Android APK.
- Безопасная сборка через GitHub Actions.
