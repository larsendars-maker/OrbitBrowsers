# Orbit Browser 1.2

Orbit is a unified Windows + Android browser ecosystem with Profiles, Sync, Themes, Downloads, History, Notes, Orbit Search and offline tools.

## Release
- Windows: `Windows`
- Android: `Android`

## Build
All release builds are performed by GitHub Actions. No manual BAT/PowerShell build is required for releases.

## Security
Do not commit `.env`, tokens, passwords, database URLs, certificates or private keys. Use Render/GitHub secrets.

## UI
Dark space/glass design with Orbit gradient branding, responsive layout, fast startup and single-window navigation.
