# Orbit Browser v1.11.0

Полированная Windows-версия Orbit Browser.

## Сборка EXE

1. Установить Python 3.13.
2. Запустить `build_windows.bat`.
3. Готовый файл: `dist\OrbitBrowser.exe`.

## Сборка Installer

Установить Inno Setup, затем запустить `build_installer.bat`.
Готовый установщик: `installer\OrbitBrowser-Setup.exe`.

Установка по умолчанию: `C:\Program Files\OrbitBrowsers`.

Имя пользователя в верхней части интерфейса берётся из текущего профиля, а не зашивается в приложение.


## Обновления и профиль
- Автоматическая проверка GitHub Releases.
- Обновление скачивает OrbitBrowser-Setup.exe с прогрессом и запускает установщик после загрузки.
- Фото профиля хранится локально в `%LOCALAPPDATA%\OrbitBrowser\data\profile_avatar.png`.
- Установщик Inno Setup показывает этапы и прогресс установки.
