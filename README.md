# Orbit Browser

**Orbit Browser** — современный браузер и единая экосистема для Windows и Android, созданная вокруг идеи персонального пространства для работы, игр и повседневного использования.

## ✦ Возможности

- 🌐 Полноценный браузер на Windows и Android
- 🗂️ Вкладки, группы вкладок и восстановление сессии
- 👤 Система профилей
- 🧩 Workspaces и Spaces
- 🎨 Orbit Studio и пользовательские темы
- 📌 Закладки и история
- 📝 Orbit Notes
- 📦 Orbit Drop
- 📋 Orbit Clipboard
- ⚡ Quick Actions и Command System
- 🔐 Orbit Account
- ☁️ Синхронизация между устройствами
- 🌍 VPN-интерфейс с поддержкой серверов, reconnect и failover
- 🔄 Автоматические обновления
- 🚀 Автоматическая сборка Windows и Android через GitHub Actions
