# Orbit Browser 1.6

Быстрый, единый и настраиваемый браузер Orbit.

## Новое в 1.6
- Режим производительности ⚡.
- Сбалансированный режим ◌.
- Внутренние страницы открываются как вкладки в одном окне и переиспользуются вместо создания дублей.
- Больше кэша WebEngine для быстрого повторного открытия сайтов.
- Сетевые операции не блокируют старт интерфейса.
- Orbit Search остаётся поиском по умолчанию.

Windows и Android собираются через GitHub Actions.
