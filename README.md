# Orbit Browser

Orbit Browser 1.0 — браузер для Windows и Android с профилями, Orbit Search, синхронизацией, темами, историей, загрузками и офлайн-инструментами.

## Установка
- Windows: скачайте `OrbitBrowser-Setup.exe` из релиза `Windows`.
- Android: скачайте `OrbitBrowser.apk` из релиза `Android`.
