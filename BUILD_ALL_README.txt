BUILD_ALL

Запустите build_all.bat на Windows. Скрипт собирает: 
- Windows portable: gotovo\OrbitBrowser\OrbitBrowser.exe
- Windows installer: gotovo\OrbitBrowser-Setup.exe
- Android APK: gotovo\OrbitBrowser-Android.apk
- Android AAB: gotovo\OrbitBrowser-Android.aab

Если Gradle не установлен, скрипт автоматически скачает Gradle 8.7 в .buildtools и использует его. Требуются интернет и Android SDK/Build Tools.
