Orbit Browser v0.8

Windows client modules:
- orbit_browser.py
- orbit_pages.py
- orbit_storage.py
- orbit_ui.py

Run:
py -3.13 -m pip install PySide6 requests
py -3.13 orbit_browser.py

Default theme: VOID (black)

The home screen is not a browser tab. Website tabs are separate and use the Chrome-like tab bar.
History/bookmarks/downloads/notes/profile/settings open inside the main window.
