GITHUB: что загружать

Этот архив предназначен для загрузки в GitHub как исходный репозиторий OrbitBrowsers.

Загружать можно:
- Python исходники Orbit Browser
- server/ backend
- android/ исходники Android
- assets/ и иконки
- build scripts
- OrbitBrowser.iss
- README.md
- .env.example
- version_info.txt

Не загружать:
- .env
- реальные пароли/API-ключи/DATABASE_URL
- готовые EXE/APK/AAB
- build/, dist/, gotovo/
- venv/, __pycache__/
- ZIP/архивы

Готовые EXE/APK/AAB публикуй отдельно через GitHub Releases.
