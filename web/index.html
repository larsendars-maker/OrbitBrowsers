Orbit Browser

Быстрый браузер нового поколения для Windows и Android. Профили, синхронизация, темы, загрузки, история и полезные офлайн-инструменты — в одном Orbit.

Что такое Orbit?

Orbit — единая экосистема браузера для компьютера и телефона. Можно использовать несколько профилей, сохранять закладки и историю, настраивать внешний вид и синхронизировать поддерживаемые данные между устройствами. Без аккаунта профиль автоматически не создаётся.

Возможности

⚡ Быстрый стартИнтерфейс открывается сразу, сетевые проверки работают в фоне.
👤 ПрофилиОтдельные настройки, данные и титулы для разных сценариев.
☁ СинхронизацияПоддерживаемые данные синхронизируются через Orbit Account.
🎨 ТемыVOID, ICE, BLUE, PURPLE, CYBER и другие варианты оформления.
📥 ЗагрузкиУправление загрузками и история без лишних окон.
🐍 ОфлайнПри отсутствии сети доступны Snake и Block Blast.
