FAQ

Коротко о загрузке и обновлениях.

Почему в GitHub иногда другая версия?

Версия определяется из файлов проекта и release workflow. В актуальной ветке все основные источники версии должны быть синхронизированы на 2.3.

Как обновляется Android?

Приложение может проверить новую версию и предложить совместимый APK. Для обновления поверх существующей установки подпись APK должна совпадать.

Где релизы?

Все опубликованные артефакты находятся в GitHub Releases.
