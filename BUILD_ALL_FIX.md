Исправленный build_all.bat

Запуск: build_all.bat

Скрипт использует пути относительно самого BAT-файла, поэтому его можно запускать из любой папки.
Windows: нужен Python 3.13, PySide6, requests и PyInstaller.
Android: нужен JDK 17+, Android SDK и интернет для одноразовой загрузки Gradle 8.7.
Результат складывается в gotovo\.
